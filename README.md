# Neovim config Yet Anotther

## About this repository

In Neovim version 0.2.0 and later, advanced features such as LSP and code completion have been introduced.

[In my current Neovim config](https://github.com/aki-ph-chem/neovim-config) uses a lot of different settings, but I want to create a “Yet Another” config that makes the most of the built-in features.

Here is our approach to third-party plugins:

- Plugins
    - If it's absolutely necessary, use the built-in `vim.pack`
    - Don't use them if standard features suffice
    - If it's extremely simple, implement it yourself
